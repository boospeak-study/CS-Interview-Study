## 스터디 소개

- **개발 지식을 학습하고, 말로 설명할 수 있는 능력을 기르는 스터디입니다.**
- 스터디는 **온라인 3회, 오프라인 1회** 비율로 진행합니다.
- 온라인 스터디에서는 **전원이 카메라를 켠** 상태로 참여합니다.
- **매주 KPT 회고**를 진행합니다. 이를 바탕으로 스터디 진행 사항을 개선해 나갑니다.

## 기여 방법

> Boospeak Study는 오픈소스 프로젝트입니다. 여러분의 기여를 환영합니다! 🙌

### 기여할 수 있는 것들

- 📝 **새로운 면접 질문 추가**: 자주 나오는 질문이나 좋은 답변을 공유해 주세요.
- ✏️ **오타 및 내용 수정**: 잘못된 정보나 오타를 발견하셨다면 수정해 주세요.
- 🧠 **CS 테스트 문제 추가**: 새로운 CS 관련 문제를 기여해 주세요.
- 🌐 **웹사이트 개선**: 디자인, UX, 기능 등 웹사이트 관련 개선 사항을 제안해 주세요.

### 기여 가이드

1. **Fork**: 이 저장소를 Fork 합니다.
2. **Clone**: Fork한 저장소를 로컬에 Clone 합니다.
   ```bash
   git clone https://github.com/YOUR_USERNAME/CS-Interview-Study.git
   ```
3. **Branch**: 작업할 브랜치를 생성합니다.
   ```bash
   git checkout -b feature/your-feature-name
   ```
4. **Commit**: 변경 사항을 커밋합니다.
   ```bash
   git add .
   git commit -m "feat: 새로운 면접 질문 추가"
   ```
5. **Push**: 변경 사항을 Push 합니다.
   ```bash
   git push origin feature/your-feature-name
   ```
6. **Pull Request**: GitHub에서 Pull Request를 생성합니다.

### 커밋 메시지 컨벤션

- `feat`: 새로운 기능 추가
- `fix`: 버그 수정
- `docs`: 문서 수정
- `style`: 코드 포맷팅 (기능 변경 없음)
- `refactor`: 코드 리팩토링
